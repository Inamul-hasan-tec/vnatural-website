# VNatural Website

A responsive brand website presenting VNatural, its natural-product sourcing approach, and supply partners.

## Tech stack

Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4, Framer Motion, and Lucide React.

## Features

- Home and About pages introducing the brand and its offerings.
- Dedicated sourcing-process and supply-partner pages.
- Gallery page describing sourcing and production categories.
- Responsive navigation and animated page sections.
- Contact form with local confirmation feedback; it does not send messages to a server.

## Getting started

Use Node.js 20.9+ and npm 9+. From the repository root:

```bash
npm install
npm run dev
```

Open http://localhost:3000. For a production build, run `npm run build`, then `npm start`. Scripts are defined in `package.json`.

This repository implements the public website. Checkout, medical consultations, and AI health services are not implemented here.
